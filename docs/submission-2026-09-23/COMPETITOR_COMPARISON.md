# THREAD: competitor context, 23 September 2026

THREAD's case should rest on completing a changed request with real inputs, returned evidence and the right authorized action. Cancellation, fast acknowledgments and revision counters already appear in other projects. The useful distinction to demonstrate is whether those mechanisms work together in one reproducible participant package. That is a proposed position, not an established performance advantage.

This is a source review, not a leaderboard. The principal branch heads below were checked on 23 September 2026. **Inspected code** means an implementation was read. **Author-reported result** means the project's own documentation or retained report describes a run. **Reproduced result** means the reviewer ran that exact artifact: no competitor results were reproduced for this comparison. Missing public evidence does not prove a feature is absent from private work.

**What THREAD should demonstrate.** Show the changed field and preserved constraints, the replacement lookup's actual result, the user's authority to act on that result, and the service's observed outcome. Then show actual audio, actual images and an unfamiliar tool schema through the same frozen participant. A readable trace matters more than another architecture label. The [demo storyboard](DEMO_STORYBOARD.md) and [evidence checklist](DEMO_EVIDENCE_CHECKLIST.md) keep these claims conditional on qualification.

Mature frameworks are engineering references, not additional contest teams. For example, [LiveKit's official turn-handling documentation](https://docs.livekit.io/agents/logic/turns/) already covers interruption handling and false interruptions. Google's official [audio](https://ai.google.dev/gemini-api/docs/audio) and [image](https://ai.google.dev/gemini-api/docs/image-understanding) guides describe actual media input support; an API capability does not establish THREAD's accuracy or timing on a particular run.

No competitor code was executed or incorporated. Interject has an MIT licence. The retained review found no general project licence grant for AccessFlow, Talent Atlas or the four newly listed projects; public visibility alone is not permission to copy their source. The comparison attributes design observations and makes no claim of first place, hidden-test success or a probability of winning.
