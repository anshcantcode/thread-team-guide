# THREAD competitor tracker

Checked: 24 September 2026. This is a map of documented product capabilities, not a measured head-to-head result. Recheck availability by device, country and account before making public claims.

THREAD's tested advantage is its visible task revision and action ledger: a correction can invalidate pending work, and completed or uncertain writes remain accounted for. The integrated branch passed 1,044 Python 3.11 tests in an isolated run. A correctly configured source run at `be11e82` scored **94.0 weighted across nine cases × three repetitions**, with 24 of 27 attempts at 100. A later **frozen packaged** run at `c2504bc` scored **90.6 weighted** under the same official procedure. The visual and unseen-tool results varied markedly between repetitions; the [package variance audit](peer-audits/packaged-variance.md) records raw-trace findings. Do not present 94.0 as a stable current score or infer hidden-set qualification. See the [source score report](benchmarks/mega-pre-local-asr-2026-09-24-3x.json), [package score report](benchmarks/mega-packaged-2026-09-24-3x.json), [pinned peer comparison](peer-audits/CLAIM_REPRODUCTION.md), and [provider route comparison](PROVIDER_ROUTE_COMPARISON.md).

## Watch rule

Check official release notes and documentation daily. Add a dated entry only when a capability materially changes THREAD's feature priorities, the Samsung test plan or a defensible demo claim. A product announcement is not an independent performance measurement. Keep hidden or private test expectations out of this file.
