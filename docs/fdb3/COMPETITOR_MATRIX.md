This is **static evidence, not a ranking**. The frozen 22-lead cohort has 21 publicly accessible repositories and one inaccessible repository. Its 34 named refs (32 branches and two tags, plus one peeled-tag object record) produce 31 per-repository complete tracked-tree snapshots, or 30 distinct tracked trees after one exact cross-repository match. These counts are not team counts or distinct working implementations. All competitor builds, tests and live runs remain unexecuted (`tests_executed: false`); strict pass, latency and cost measurements are unknown.

The cohort contains 16 repositories with inspected agent/prototype source, two planning/template-only leads, three contextual projects that are not presently comparable to 2026 Theme 5, and one inaccessible lead. Public access/identity and comparison relevance are separate fields.

## Identity and coverage

The old extension filter omitted JSX/TSX, Kotlin/Java and HTML and excluded lockfiles and tests. The repaired auditor fingerprints **every tracked path, mode, type and Git object ID**, including locks, build files, UI, tests, assets and documentation. It hashes inspected source blobs separately with SHA-256. Consequently an equal fingerprint supports an identical tracked-tree statement only; it does not establish semantic equivalence, matching dependencies at execution time, or equal runtime behavior. Documentation-only differences can create extra snapshots. Submodule contents, Git LFS payloads, untracked files and external model/service dependencies are not dereferenced or validated. Credential-like filenames are inventoried by Git object ID but their contents are not read.

Public refs were refreshed without authentication. Bare Git object reads and hashing were the only operations performed on competitor content. No checkout, imported competitor module, dependency installer, build hook or test was run. The unavailable OS sandbox (registered WSL disks missing; Docker CLI unavailable per coordinator evidence) blocks safe execution. INR 0 is authorized for paid resources. Neither constraint turns an untested competitor into a failure.
